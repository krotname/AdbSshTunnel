# Профиль выпуска ADB SSH Tunnel

| Поле | Значение |
|---|---|
| Репозиторий | `krotname/AdbSshTunnel`, public, main |
| Package | `name.krot.adbsshtunnel` |
| Публичная версия | `app/build.gradle`: 1.1.2 (SemVer 2.0.0) |
| Android versionCode | 4; отдельное техническое поле |
| APK | Один APK с arm64-v8a и x86_64 |
| Сборка | Red / Linux, изолированный непривилегированный ARC job с постоянным кэшем; Windows-сборки только White |
| Toolchain | SDK 36 / JDK 21 / Java 17 / AGP 8.10.1 / Gradle 8.11.1 |
| Native | Sshd4a `897f9064a7279bff89538ec87729c43888f3b83d`, NDK 27.2.12479018, CMake 3.22.1 |
| Проверки | testReleaseUnitTest, lintRelease, assembleRelease, native restrictions, root-controller host tests, signature, devices |
| Подпись | Один постоянный RSA release key, PKCS12 в Vaultwarden |
| Сертификат SHA-256 | `dc2e82bcffeb5bed6cdc2f0a6db12368a9437bd307deb79b7730f58dd523fee0` |
| Канал выпуска | GitHub Release; магазины пока не подключены |

Подпись выполняется отдельно после проверки APK. Сборочные процессы не получают
ключ. В Google Play передаётся тот же app signing key; отдельный ключ подписи
приложения не создаётся. Отпечаток сертификата записывается после создания
и чтения канонического ключа из сейфа (проверено 06.10.2026).

Тестовый Pixel — стенд разработки; все испытания выполняются на нём.
До установки на рабочий Fold обязательны положительные и отрицательные
SSH-сценарии, root разрешён/запрещён, отказ controller и firewall, Wireless Debugging и смена
его порта, плитка и интерфейс. На Pixel также проверяются независимость
WireGuard/SSH, четыре реальные перезагрузки, сон/смена сети и три сопоставимых
интервала батареи по 30 минут без зарядки. Старые результаты другого APK
не засчитываются.

Fold — рабочий телефон владельца: только установка готового
подписанного APK, проверенного на Pixel, штатная настройка и проверка результата
установки без удаления данных и смены host key. Испытания на Fold допускаются
только по отдельному прямому поручению владельца именно на них. Подключение
кабеля не разрешает переключения сети, перезагрузки или замеры на Fold.
Отсутствие SIM на Pixel фиксируется как ограничение реальной mobile/WAN-приёмки;
оно не разрешает переносить испытания на Fold или считать их пройденными.

Исходники и APK публикуются только после обязательных CI, одного Security Review,
merge, CI на main и проверки скачиваемого и установленного артефактов.
