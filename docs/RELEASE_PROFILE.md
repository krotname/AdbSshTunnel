# Профиль выпуска ADB SSH Tunnel

| Поле | Значение |
|---|---|
| Репозиторий | `krotname/AdbSshTunnel`, public, main |
| Package | `name.krot.adbsshtunnel` |
| Версия | `app/build.gradle`: 1.0.0 / 1 |
| APK | Один APK с arm64-v8a и x86_64 |
| Сборка | Black, изолированный контейнер UID/GID 1000, без сети и секретов |
| Toolchain | SDK 36 / JDK 21 / Java 17 / AGP 8.10.1 / Gradle 8.11.1 |
| Native | Sshd4a `897f9064a7279bff89538ec87729c43888f3b83d`, NDK 27.2.12479018, CMake 3.22.1 |
| Проверки | testReleaseUnitTest, lintRelease, assembleRelease, native restrictions, signature, devices |
| Подпись | Один постоянный RSA release key, PKCS12 в Vaultwarden |
| Сертификат SHA-256 | `dc2e82bcffeb5bed6cdc2f0a6db12368a9437bd307deb79b7730f58dd523fee0` |
| Канал выпуска | GitHub Release; магазины пока не подключены |

Подпись выполняется отдельно после проверки APK. Сборочные процессы не получают
ключ. В Google Play передаётся тот же app signing key; отдельный ключ подписи
приложения не создаётся. Отпечаток сертификата записывается после создания
и чтения канонического ключа из сейфа (проверено 06.10.2026).

Приёмка: сначала тестовый Pixel (identity проверяется через USB), затем Fold.
До установки на Fold обязательны положительные и отрицательные SSH-сценарии,
root разрешён/запрещён, отказ помощника, Wireless Debugging и смена его порта,
плитка, интерфейс и реальный WAN. Старые результаты другого APK не засчитываются.
После Fold: независимость WireGuard/SSH, четыре реальные перезагрузки,
сон/смена сети и три сопоставимых интервала батареи по 30 минут без зарядки.

Исходники и APK публикуются только после обязательных CI, одного Security Review,
merge, CI на main и проверки скачиваемого и установленного артефактов.
