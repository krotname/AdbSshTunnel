# Приёмка постоянного SSH-порта и сетевых списков

Одна команда клиента должна работать при смене системного Wireless Debugging
порта: SSH `19191`, назначение `127.0.0.1:5555`. Назначение внутри SSH виртуальное:
сервер переводит его в проверенный текущий локальный ADB-порт. Оно не создаёт
новый прямой ADB listener. Nonroot не включает и не заменяет системный adbd.

| Сценарий | Ожидаемый результат |
|---|---|
| Системный TLS-порт A → B | Старый сеанс закрыт; та же команда клиента подключается к B |
| Wireless Debugging выключен | Новые каналы запрещены; активный SSH/ADB закрыт |
| Чёрный и белый списки содержат одну сеть | Запрет имеет приоритет |
| Пустой белый список | Listener отсутствует; видна причина |
| Режим чёрного списка, известная сеть | Разрешена, пока нет точного запрета |
| Идентификатор скрыт или разрешение отозвано | Доступ закрыт; видна причина и способ восстановления |
| Wi-Fi SSID сменился при том же IP | Старые соединения закрыты; новое решение по SSID |
| Wi-Fi и mobile доступны одновременно | Listener только на разрешённых сетях; IMS исключён |
| Добавление, изменение, удаление правила | Сохранение после пересоздания Activity и процесса; немедленный отзыв |
| Другой host/port, exec, PTY, SFTP, reverse, пароль | Отказ |
| Root запрещён или helper отсутствует | Отказ; nonroot не получает root |
| VPN/WireGuard включён и выключен | Политика физических сетей независима; без изменения маршрутизатора |

Сначала подписанный кандидат на Pixel: протокол, отзыв, политика, интерфейс,
root/nonroot, порт и смена сети. Затем обновление Fold без удаления данных,
проверка мобильной сети и исходного host key. SIM отсутствует на Pixel:
положительную mobile-приёмку выполнять на Fold, с отдельным результатом для
CGNAT/входящей достижимости. Далее — матрица перезагрузок, сна и физические
интервалы батареи из RELEASE_PROFILE. Результаты конкретных устройств остаются
в существующем локальном checkpoint.
