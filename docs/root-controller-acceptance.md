# Управление ADB приложением: приёмка 1.1.0 / 2

Прямой ADB и SSH имеют отдельные политики. Постоянный ADB должен работать при
выключенном SSH; его явное отключение сохраняет USB и защиту TLS-портов.
Новые установки разрешают только loopback до задания доверенных сетей.

## Установка и переход

1. Проверить аппаратное устройство, release-подпись, версию и сохранность ключей.
2. Для перехода сохранить на время операции заменяемые файлы и прежнее состояние,
   запустить автономный откат, проверить его процесс независимо от ADB-сеанса.
3. Установить подписанный APK с сохранением данных. Настроить controller через
   вкладку ADB или приватный RootSetupReceiver из существующего root/USB-сеанса.
4. Проверить root-владельца, режимы 0700/0600, обе firewall-семьи, listener,
   watcher и независимость от SSH. Сохранить действующую политику доверенных сетей.
5. Отделить AdAway, перенеся его функцию и файл бюджета в самостоятельный каталог.
   Сохранить 15 минут, настройки владельца, cooldown и лимиты; живой webserver
   не останавливать. Проверить, что новый wrapper не изменяет ADB.
6. Остановить только подтверждённый старый ADB-watchdog. Удалить его boot hooks,
   внешний helper и ненужное состояние, затем только старые собственные цепочки.
   Повторить миграцию: результат и число процессов должны остаться прежними.
7. После независимой проверки связи отменить откат и удалить временные копии.

Ранний hook вызывает guard синхронно, затем запускает native watcher. До
готовности Android Wi-Fi не считается доверенным. Неизвестная идентичность,
ошибка запроса или неподдерживаемый формат закрывают исключение интерфейса.
INPUT защищает известные порты adbd, OUTPUT ограничивает также новые TLS-порты
до очередного чтения /proc. Controller изменяет только AST_ADB_IN и AST_ADB_OUT.

## Матрица Pixel

| Сценарий | Требуемый результат |
|---|---|
| Чистая установка, legacy, повторный переход, обновление APK | Одна версия watcher, ключи и USB сохранены |
| Разрешённый Wi-Fi, hotspot, WireGuard | Прямой ADB доступен согласно отдельной политике |
| Запрещённый/неизвестный Wi-Fi, mobile | Прямой ADB закрыт; SSH следует своей политике |
| Отзыв доверия, динамические TLS-порты | Прежнее исключение отозвано; новый порт защищён |
| Root разрешён, nonroot, отказ root | SSH остаётся UID приложения; отказ явно показан |
| Listener исчез, watcher остановлен, firewall повреждён | Ограниченное восстановление; TCP закрыт при отказе защиты |
| Исправные adbd / SSH / AdAway | Нет лишних перезапусков |
| Четыре перезагрузки | Guard до разблокировки; одна копия watcher после загрузки |
| Сон и смена сети | Политика и доступ восстанавливаются согласно настройкам |
| Три интервала по 30 минут без зарядки | Измерения нового APK, связь проверена на границах |

Отсутствие SIM фиксируется как непроверенная реальная мобильная сеть. Fold не
заменяет Pixel в испытаниях. После Pixel на Fold разрешены штатная установка и
настройка через проверенный USB с откатом; перезагрузки и батарея туда не входят.

Фактические результаты, точные SHA, версии и ограничения сохраняются в
существующем приватном checkpoint выпуска; эта таблица сама по себе не является
свидетельством прохождения испытаний.
