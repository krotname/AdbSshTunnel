# Linux tunnel (delta: linux-snap-reap)

## MODIFIED Requirements

### Requirement: Фоновая служба сохраняет управление

На Debian Linux SHALL управлять шлюзом через пользовательскую
`adb-ssh-tunnel.service`. В строго изолированном Snap Linux SHALL вместо
этого запускать и контролировать собственный дочерний процесс `serve`
в resident-процессе GUI: закрытие окна скрывает его и сохраняет
включённый туннель; явный Quit останавливает туннель и закрывает
приложение. Скрытый автозапуск (`--hidden`, запускаемый `snap userd`,
когда включён «Запуск при входе») SHALL поднимать включённый туннель
без показа окна. Явная остановка SHALL закрывать туннель. Приложение
SHALL оставлять SDK server, системный sshd и маршрутизацию под
управлением пользователя. Остановленный дочерний процесс SHALL быть
подобран (reap), зомби не накапливаются.

#### Scenario: Окно закрыто и открыто снова

- **WHEN** UI закрывается при включённой службе
- **THEN** служба продолжает работу с учётом политики, повторно открытый UI показывает её текущее состояние

#### Scenario: Остановленный serve подобран без зомби

- **WHEN** супервизор останавливает дочерний `serve`
- **THEN** процесс завершается и подбирается (wait); повторные
  старт/стоп не оставляют зомби-процессов
